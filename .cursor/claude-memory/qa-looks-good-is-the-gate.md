When QA replies "QA looks good" to a test-case draft, treat it as the "looks good" gate: save is already done, start the script stage.

**Why:** QA corrected this on 2026-10-30 ("you asked for looks good and I said QA looks good, it's the same thing").
**How to apply:** any short approval of a case draft passes the gate in the workflow-testing skill. Do not re-ask. See [[no-unnecessary-stops]].
