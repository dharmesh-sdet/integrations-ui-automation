# Blocked

Post this when a ticket cannot be retested until other bugs are fixed. Do not
change the ticket status unless the user asks. Once the blocking bugs are
fixed, verify them first (Verification on each), then post the full retest
table on this ticket.

No verbatim example is available. The original Blocked comment on AL-4064
(blocked by AL-4109 and AL-4110) is no longer on the ticket. This shape
follows the other labelled comments; confirm the wording with the user the
first time you use it.

```
**Blocked:** Cannot complete the retest of <Trigger name> trigger, <Activity name> activity on <Staging | Production> until AL-XXXX (<short summary>) and AL-YYYY (<short summary>) are fixed.
```
