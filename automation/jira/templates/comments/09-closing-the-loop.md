# Closing the loop

Post this on a ticket that was reopened, or kept open, only because of
another ticket that is now fixed. One or two sentences.

```
AL-XXXX confirmed fixed on <Staging | Production>. <What now works> when <activity/flow> runs on this trigger. Closing the loop on this ticket.
```

## Real example (AL-4002, comment 77340)

```
AL-4053 confirmed fixed on Staging (pyxis). All configured field mappings across Contact, Company, and Deal properties now sync correctly when the Add Prospect in Saleshandy activity runs on this trigger. Closing the loop on this ticket.
```
